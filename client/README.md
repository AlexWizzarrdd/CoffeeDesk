## Команды

npm install - установить все зависимости
npm install --production - установить только продуктовые зависимости
npm run dev - запуск приложения в режиме разработки
npm run build - собрать продуктовую сборку
npm run lint - проверка стиля кода и поиск ошибок
npm run preview - просмотр собранной продуктовой сборки
