# CoffeeDesk

CoffeeDesk — внутренний веб-сервис для управления сотрудниками, сменами и запросами на изменение расписания в кофейне.

Проект решает задачи планирования, контроля и коммуникации между бариста, менеджерами и администраторами.

---

## Основные возможности

### Пользователи и роли
- Бариста и стажёры: просмотр смен, отправка запросов на изменение смен, уведомления
- Менеджеры: управление сменами, обработка запросов, просмотр статистики
- Администраторы: полный доступ, управление пользователями и ролями

### Смены и календарь
- Календарь смен
- Добавление, редактирование и удаление смен (manager/admin)
- Автогенерация смен на месяц
- Детальное окно дня

### Запросы на изменение смен
- Типы запросов: swap, drop, move, other
- Отправка запросов сотрудниками
- Одобрение или отклонение менеджером / администратором
- Комментарии к решениям

### Уведомления
- Назначение и изменение смен
- Запросы на изменение смен
- Решения по запросам
- Для manager/admin — действия прямо в уведомлении
- Для barista/intern — только отметка прочтения

### Задачи
- Назначение задач сотрудникам
- Индикатор количества активных задач

### Статистика
- Плановые и фактические часы работы
- Отчёты по сотрудникам

## Запуск проекта

### Backend
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

---
### Backend
cd client
npm install
npm run dev

Frontend: http://localhost:5173
Backend API: http://localhost:8000/api/
